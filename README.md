## ⚙️ Prerequisites & Setup

### Requirements
- Basic familiarity with `JavaScript`
- Git installed on your local machine

### Installation Steps
```bash
# 1. Clone repository
git clone https://github.com/JasminPeer/Smart-Learning-Progress-Intelligence-System.git
cd Smart-Learning-Progress-Intelligence-System

# 2. Install dependencies (client and server)
npm run build

# 3. Setup environment variables (create a .env in server/)
# PORT=5000
# MONGODB_URI=your_mongodb_connection_string

# 4. Verify database connection
node verify-db.js

# 5. Start the backend server
npm start
```
